Calculadora Gestacional

Uma calculadora gestacional simples e intuitiva desenvolvida com HTML, CSS e JavaScript. O projeto permite calcular informações importantes da gestação com base na Data da Última Menstruação (DUM).

Funcionalidades
Cálculo da idade gestacional em semanas e dias
Estimativa da Data Provável do Parto (DPP)
Interface responsiva e fácil de usar
Cálculos realizados instantaneamente no navegador
Projeto leve, sem necessidade de backend
Tecnologias Utilizadas
HTML5
CSS3
JavaScript
Como Usar
Insira a Data da Última Menstruação (DUM)
Clique no botão de calcular
Veja automaticamente:
Idade gestacional atual
Data provável do parto
Informações relacionadas à gestação
Objetivo do Projeto

Este projeto foi desenvolvido para praticar conceitos de desenvolvimento web front-end, manipulação de datas em JavaScript e criação de interfaces responsivas.

Aviso

Os resultados fornecidos são estimativas e não substituem acompanhamento médico profissional.
